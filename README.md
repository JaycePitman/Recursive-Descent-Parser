# Recursive-Descent-Parser
A recursive Descent parser for a made up language created in Java.

# Assignment Description
In this project you are to implement a scanner and a recursive descent parser for a small
programming language (let’s call it Hawk). Your program will take as input a program written in
the provided language. In addition to parsing the input programs, your program must generate
the proper errors when encountered. 

# Running Test Cases
All sample test cases are in the 'TestCases' folder. Provide the program the file path to one of the input files and check the program's answer with the corresponding output file. 
For example: give the parser the file path to input1.txt, then check the program's output with output1.txt
